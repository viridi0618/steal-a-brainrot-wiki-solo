# Steal a Brainrot Wiki

> The complete community wiki for Steal a Brainrot — a Roblox collection game where you gather brainrots (internet meme-themed characters). 24M+ daily players, 100+ brainrots to collect.

## About

Steal a Brainrot is a free-to-play Roblox collection game where you collect brainrots that generate passive income (M/S — millions per second). Trade with other players, participate in weekly events (Admin Abuse, Taco Tuesday), discover hidden rituals, and master the Rebirth system for permanent bonuses.

This wiki covers every aspect of the game, maintained by the community.

## Live Site

**[stealabrainrot.wiki](https://stealabrainrot.wiki)**

## What's Inside

- **Brainrots** — All brainrots with base income rates, rarity tiers, and collection tips
- **Traits** — Complete trait database with effects, multipliers, and acquisition methods
- **Index** — In-game collection tracker — which brainrots are registered and which are not
- **Best Brainrots** — Tier rankings and meta recommendations for early and late game
- **Admin Abuse** — Weekly admin event guide with schedule, rewards, and tips
- **Taco Tuesday** — Weekly Tuesday event with special rewards and bonuses
- **Rituals** — Hidden combinations requiring 3-4 players to unlock special brainrots
- **FAQ** — Frequently asked questions about gameplay, mechanics, and events

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org) (App Router)
- **Deployment:** [Vercel](https://vercel.com)
- **Styling:** Tailwind CSS
- **Analytics:** Google Analytics 4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
```

## Contributing

This is a community-maintained wiki. If you spot inaccurate info, missing content, or want to add a guide:

1. Fork the repo
2. Create a branch (`git checkout -b fix/brainrot-stats`)
3. Commit your changes
4. Open a PR

All game data lives in `src/lib/data.ts` — that's where most content updates go.
